# RAG Chat с VseGPT

Этот проект включает в себя инструменты для обработки данных PubMed и других документов, создания векторных баз данных и чат-интерфейса с использованием поиска по релевантности (Retrieval Augmented Generation, RAG).

## Установка зависимостей

```bash
poetry install
```

## Подготовка API ключа

Создайте файл `api_keys.env` и добавьте в него свой API ключ VseGPT:
```
VSEGPT_API_KEY=ваш_ключ_api
```

## Структура проекта

- `pubmed_downloads/` - директория для скачанных XML файлов PubMed
- `pubmed_txt/` - директория для текстовых файлов PubMed
- `pubmed_db_index/` - директория для хранения векторной базы PubMed
- `user_documents/` - директория для пользовательских документов
- `docs_db_index/` - директория для хранения векторной базы пользовательских документов
- `texts/` - директория для извлеченных текстов из документов

## Рабочий процесс

### 1. Скачивание данных PubMed (опционально)

```bash
# Скачивание файлов PubMed
python download_pubmed.py --baseline 5 --update 5
```

### 2. Обработка файлов PubMed в текстовый формат

```bash
# Обработка XML.GZ файлов в текстовый формат
python process_pubmed_to_txt.py --input-dir pubmed_downloads --output-dir pubmed_txt
```

### 3. Извлечение текста из документов

```bash
# Извлечение текста из PDF, DOCX и PPTX файлов
python file_texts.py
```

### 4. Создание векторных баз данных

#### Создание базы из PubMed текстов
```bash
# Обработка текстовых файлов PubMed
python rag_db_test_pubmed.py --input-dir pubmed_txt --output-dir pubmed_db_index
```

#### Создание базы из пользовательских документов
```bash
# Обработка документов
python rag_db_test_user_documents.py
```

## Поиск по векторным базам

Проект поддерживает два типа векторных баз:
- `pubmed_db_index` - для статей PubMed
- `docs_db_index` - для пользовательских документов

### Поиск с использованием rag_db_search.py

```bash
# Поиск по обеим базам данных
python rag_db_search.py "ваш запрос"

# Интерактивный режим
python rag_db_search.py --interactive
```

## Использование RAG с GPT для ответов на вопросы

```bash
# Запуск с использованием VseGPT API
python rag_gpt_fallback.py "ваш вопрос"
```

## Аргументы командной строки

### download_pubmed.py
- `--baseline`: Количество файлов baseline для скачивания (по умолчанию: 5)
- `--update`: Количество файлов update для скачивания (по умолчанию: 5)
- `--threads`: Количество потоков для параллельного скачивания (по умолчанию: 3)

### process_pubmed_to_txt.py
- `--input-dir`: Директория с .xml.gz файлами (по умолчанию: pubmed_downloads)
- `--output-dir`: Директория для сохранения текстовых файлов (по умолчанию: pubmed_txt)
- `--threads`: Количество параллельных потоков обработки (по умолчанию: 4)

### rag_db_test_pubmed.py
- `--input-dir`: Директория с текстовыми файлами (по умолчанию: pubmed_txt)
- `--output-dir`: Директория для сохранения векторной базы (по умолчанию: pubmed_db_index)
- `--chunk-size`: Размер чанка текста (по умолчанию: 1024)
- `--chunk-overlap`: Перекрытие между чанками (по умолчанию: 200)
- `--model`: Модель для эмбеддингов (по умолчанию: sentence-transformers/all-MiniLM-L6-v2)
- `--max-files`: Максимальное количество файлов для обработки
- `--append`: Добавить к существующему индексу

### rag_db_search.py
- `--model`: Модель для эмбеддингов (по умолчанию: sentence-transformers/all-MiniLM-L6-v2)
- `--top-k`: Количество результатов для вывода (по умолчанию: 3)
- `--no-gpt`: Только поиск без запроса к GPT
- `--use-pubmed`: Использовать только базу PubMed
- `--use-docs`: Использовать только базу обычных документов
- `--interactive`: Интерактивный режим для повторных запросов

## Особенности проекта

### Обработка разных типов документов

Поддерживаются следующие форматы:
- PDF (через PyMuPDF/fitz)
- DOCX (через python-docx)
- PPTX (через python-pptx)
- Текстовые файлы PubMed

### Многопоточная обработка данных

- Параллельное скачивание файлов PubMed
- Многопоточная обработка XML документов

### Эффективное хранение и обновление векторных баз

- Хеширование файлов для отслеживания изменений
- Инкрементальное обновление индексов
- Кэширование результатов для оптимизации вычислений

### Интеграция с VseGPT API

- Гибкая настройка параметров генерации
- Контекстно-зависимые ответы на основе найденных документов
- Возможность выбора различных моделей
